Ringkasan Tugas & Tanggung Jawab Backend Engineer (Junior–Mid)
1. Pengembangan Backend

Mengimplementasikan fitur dan layanan backend dengan tingkat kompleksitas menengah.

Menulis kode yang bersih, terstruktur, serta mengikuti standar dan best practice.

Mendesain dan mengoptimalkan API, service layer, dan integrasi data.

2. Pemeliharaan & Penyelesaian Masalah

Melakukan debugging dan root cause analysis pada isu fungsional maupun performa.

Memperbaiki bug dan memastikan stabilitas sistem.

Menganalisis log dan monitoring untuk memverifikasi perilaku sistem. Bisa dalam bentuk OCP log maupun gravana / elastic search

3. Pengujian & Kualitas Kode

Membuat unit test dan integration test.

Memastikan reliabilitas dan kompatibilitas fungsi backend.

Berpartisipasi dalam code review untuk menjaga kualitas codebase.

4. Kolaborasi Teknis

Berkoordinasi dengan tim frontend, QA, DevOps, dan engineer lain untuk memastikan integrasi berjalan optimal.

Memberikan masukan teknis dalam diskusi desain dan perencanaan sprint.

Mendukung engineer junior ketika diperlukan.

5. Pengelolaan Layanan & Infrastruktur

Memahami alur backend end-to-end: controller → service → repository → database → external services.

Mengelola integrasi API eksternal, caching, dan mekanisme asynchronous.

Berkontribusi dalam deployment dan perbaikan performa.

6. Peningkatan Berkelanjutan

Mengidentifikasi area untuk refactoring dan optimasi.

Mengadopsi teknologi atau pendekatan baru untuk peningkatan efisiensi.

Melakukan pembelajaran berkelanjutan untuk mendukung perkembangan teknis.
